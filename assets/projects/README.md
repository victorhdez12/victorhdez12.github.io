# Project image sources

- `earth-eastern-hemisphere.webp`: public-domain Earth imagery, [Earth Eastern Hemisphere](https://commons.wikimedia.org/wiki/File:Earth_Eastern_Hemisphere.jpg), used as the visual base for the satellite-pass concept. Orbit lines on top are schematic, not computed results.
- `apophis-proximity-trajectories.webp`: original trajectory research plot from Victor's Apophis/DLR research files; compares proximity trajectories for three tetrahedral density models.
- `megasat-paper-cover.webp`: upper-page crop rendered from the supplied MegaSat IAC 2024 conference paper PDF, showing the published title, author list and abstract.
